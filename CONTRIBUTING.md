# Contributing

Thank you for helping. Issues and pull requests are welcome.

## Adding or changing an egg

- One egg per file in the `eggs` folder, named `egg-<name>.json`, in the Pterodactyl egg format (PTDL_v2).
- Write names, descriptions and comments in English.
- Do not put tokens, passwords or links to a single project into an egg. Eggs here are generic.
- Test the import in a panel and start a server from the egg before you open a pull request. Tell us which panel and version you used.
- Use Unix line endings in install scripts.

## Questions

Ask in [Discussions](https://github.com/EpicWing/eggs/discussions), on Discord (https://discord.gg/tc7xtNPsmh) or by email (support@epicwing.de).
